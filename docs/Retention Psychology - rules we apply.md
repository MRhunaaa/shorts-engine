# Retention psychology → concrete edit rules

Honest note: a short can't "fix" anhedonia (that's a clinical state; it needs real-life help, not more stimulation).
What we *can* do: viewers numbed by endless fast content still respond to **curiosity, a character to root for,
earned surprise, and a satisfying payoff**. Pure overstimulation (random flashes, noise) makes numbness worse; *meaningful*
change keeps attention. So every rule below ties stimulation to story.

| Principle | What it means | Rule in our edit |
|---|---|---|
| Curiosity gap (Loewenstein) | People keep watching to close an open question | Line 1 = a paradox stated as fact; frame 0 shows the paradox, not a logo or a setup |
| Prediction error = dopamine | The brain rewards *unexpected* good outcomes, not constant ones | 2-3 real surprises (gags) at unpredictable spots, not on a fixed beat |
| Pattern interrupt | Attention decays in ~2-3 s without change | Something meaningful changes every 1.5-3 s: angle, expression, prop, effect, SFX |
| Underdog + vindication | We root for the mocked one; their win feels like *ours* | Mockery shown on screen (laughs, HA!), stakes rise, then the vindication beat gets the biggest hit (burst, sting, crowd) |
| Faces & emotional contagion | We mirror faces | Big expressive faces in MCU; reactions land 0-3 f before the word |
| Contrast | A win only feels big next to a loss | Rival / expert fails first (crash, splash), then our hero succeeds |
| Clear payoff + callback | Closure releases tension; a callback feels clever | Last line pays off line 1 (same prop on screen), so it can loop |
| Loop / rewatch | Seamless end → start invites a replay | Final frame visually matches frame 0 (same prop/angle) |
| Pace | Reference narrator 3.5-4.1 words/s | Use eleven_multilingual_v2 + Ethan (3.6 w/s); total length 25-30 s |
| Sound as reward | Hits, whooshes and stings mark rewards | Sparse SFX on story events only; music stops before the payoff, sting on the last word |

## Checklist before rendering
- [ ] Frame 0 shows the paradox prop/character (no empty establishing shot)
- [ ] No 3-second stretch without a meaningful change
- [ ] At least 2 unexpected gags
- [ ] The failure beat (contrast) comes before the vindication beat
- [ ] The last frame calls back to frame 0
- [ ] Maximum one whip, always blurred; everything else glides or dissolves (measured reference)
