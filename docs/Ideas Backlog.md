# Ideas backlog

## Horror: REAL-story documentary episodes (rule since 2026-11-23)
Process for each candidate: (1) find the original reports (national/regional news, archives, published testimonies), (2) record the source links + dates in the episode note, (3) script in documentary voice ("menurut warga…", "dilaporkan…", "katanya…"), (4) list the sources in the description. Nothing goes in the script that the sources don't support. Survivor stories first; never sensationalise a child's death or a recent tragedy.
